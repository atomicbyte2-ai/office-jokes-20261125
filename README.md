# One-Line Office Jokes

> The office printer has paper, ink, and power — and a personal vendetta against page two.

`main.ts` holds the one-line office joke as a constant, validates it against the bounty gate (1–199 characters, a single line, not only whitespace, no control characters), then writes it to `entry.txt` inside `MAKEFUN_OUTPUT_DIR` (default `/output`) with no trailing newline, and logs the character count.
